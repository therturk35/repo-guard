# Güvenlik Politikası
repo-guard'da bir açık bulursan lütfen herkese açık issue açma. GitHub'ın **Security → Report a vulnerability** (özel bildirim) özelliğini kullan. 7 gün içinde yanıt vermeye çalışırım.

Kapsam: tarayıcının taranan içerik tarafından kandırılması (ör. çalıştırılma, ReDoS, rapora kaçış dizisi sızması, sırların raporda maskelenmemesi), `fetch` komutunun güvenli olmayan git davranışı.
